Your Info and Privacy

How Your Information is Kept & Stored

Winter values user privacy and minimizes data collection to only what is strictly necessary for utility features to function properly. All stored data is saved locally in structured JSON configuration files on our secure private server environment.

  • Name & Nickname History (names_history.json): Stores recent display names and nicknames when user updates occur so members can inspect their own name logs via ,nh or wipe them completely via ,clearnames.
  • Server Moderation & Jail Settings (settings.json & modlog_cases.json): Stores server configuration parameters, such as designated jail/mod log channels, custom prefixes, honeypot settings, and auto-incrementing case numbers.
  • Filter Settings (filter_settings.json): Retains word blacklist keywords configured by server administrators for automated chat cleanup.
  • Giveaways & Welcome Settings (giveaways.json, welcome_settings.json): Temporarily stores active giveaway parameters (host ID, end timestamp, prize) and greeting embed formats.
  • Timezones (settings.json): Retains user-specified timezone strings set via ,tz set.

Message Content & Ephemeral Data Handling

Winter processes live message content in real-time strictly for functional execution and does not store unflagged chat histories to disk:

  • Automated Chat Moderation: Messages are scanned transiently in memory to check against active server word filters or spam thresholds. Messages that trigger filters are deleted instantly.
  • Snipe Commands (,snipe / ,rs): Recently deleted messages and removed reactions are cached strictly in temporary memory (RAM) per channel for short windows before being overwritten. They are never written to permanent disk storage.
  • Honeypot Traps: Messages sent inside administrator-designated honeypot channels are captured to issue softbans and cleared automatically.

Third-Party Sharing & Rights

We do not sell, trade, or share user data or message records with any third-party advertising or analytics networks. Data is utilized exclusively to deliver bot commands within your Discord server.

Users may wipe their personal name logs at any time using ,clearnames or request server data deletion upon bot removal from their server.
